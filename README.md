# 🌙 ShadowKnight 2D Adventure

*A lightweight 2D platformer adventure game inspired by Hollow Knight*

**لعبة مغامرات ثنائية الأبعاد خفيفة مستوحاة من Hollow Knight**

## 📖 Overview | نظرة عامة

**English:**
ShadowKnight is a modern, lightweight 2D platformer adventure game that brings the essence of Hollow Knight's exploration and combat to a streamlined, accessible experience. Built with cutting-edge programming techniques using Python and Pygame, this project focuses on smooth gameplay mechanics, elegant minimalist graphics, and intelligent AI-driven enemy behavior.

**العربية:**
سادو نايت هي لعبة مغامرات منصات ثنائية الأبعاد حديثة وخفيفة تجلب جوهر الاستكشاف والقتال من Hollow Knight في تجربة مبسطة وسهلة الوصول. مبنية بتقنيات برمجية متطورة باستخدام Python و Pygame، يركز هذا المشروع على آليات اللعب السلسة والرسومات الأنيقة والبسيطة وسلوك الأعداء المدعوم بالذكاء الاصطناعي.

## 🎮 Key Features | الميزات الأساسية

### Core Gameplay | اللعب الأساسي
- **Fluid Movement System** | نظام حركة سلس - Responsive character controls with precise platforming mechanics
- **Combat Mechanics** | آليات القتال - Lightweight yet satisfying combat system with combo attacks
- **Exploration Elements** | عناصر الاستكشاف - Interconnected levels with secrets and collectibles
- **Progressive Difficulty** | صعوبة تدريجية - Balanced challenge curve suitable for all skill levels

### Technical Excellence | التميز التقني
- **Python + Pygame Engine** | محرك Python + Pygame - Optimized for performance and cross-platform compatibility
- **AI-Powered Enemies** | أعداء مدعومون بالذكاء الاصطناعي - Smart enemy behavior with adaptive difficulty
- **Minimalist Art Style** | أسلوب فني بسيط - Beautiful pixel art with efficient resource usage
- **Smooth Audio Integration** | تكامل صوتي سلس - Dynamic sound effects and ambient music

## 🛠️ Technology Stack | المكدس التقني

- **Programming Language** | لغة البرمجة: Python 3.9+
- **Game Engine** | محرك اللعبة: Pygame 2.5+
- **Graphics** | الرسومات: Custom pixel art assets
- **Audio** | الصوت: Pygame mixer with OGG/WAV support
- **AI Framework** | إطار عمل الذكاء الاصطناعي: Custom behavior trees
- **Build System** | نظام البناء: PyInstaller for distribution

## 🚀 Why Lightweight Design? | لماذا التصميم الخفيف؟

**Performance First** | الأداء أولاً
- Optimized for older hardware and mobile devices
- Fast loading times and smooth 60 FPS gameplay
- Minimal system requirements (2GB RAM, integrated graphics)

**Developer Friendly** | ودود للمطورين
- Clean, modular codebase for easy contribution
- Comprehensive documentation and examples
- Extensible architecture for additional features

**Accessibility Focus** | التركيز على إمكانية الوصول
- Support for multiple input methods
- Colorblind-friendly visual design
- Adjustable difficulty settings

## 📋 Installation & Setup | التثبيت والإعداد

```bash
# Clone the repository
git clone https://github.com/KaizerAE/ShadowKnight-2D-Adventure.git
cd ShadowKnight-2D-Adventure

# Install dependencies
pip install -r requirements.txt

# Run the game
python main.py
```
